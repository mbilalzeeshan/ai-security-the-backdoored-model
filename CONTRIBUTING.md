# Contributing

Thanks for contributing to this controlled AI/ML security lab.

## Guidelines

- Keep demonstrations isolated and non-destructive.
- Do not add real credentials, secrets, or weaponized payloads.
- Prefer sanitized examples when documenting unsafe deserialization behavior.
- Explain the security impact and defensive takeaway for new lab material.
- Keep evidence and reproducibility notes clear enough for another learner to follow.

## Pull requests

1. Describe the security or documentation change.
2. Explain how you tested it, if applicable.
3. Keep unrelated changes out of the pull request.
